QUESTIONS 01 - 30: SAP MM – P2P CYCLE TECHNICAL MCQS
--------------------------------------------------------------------------------
Q01. What does P2P stand for?
     A) Plan to Product
     B) Procure to Pay
     C) Purchase to Production
     D) Product to Payment
     >> CORRECT ANSWER: B) Procure to Pay

Q02. Which T-code is used to create a Purchase Requisition?
     A) ME21N
     B) ME51N
     C) MIGO
     D) MIRO
     >> CORRECT ANSWER: B) ME51N

Q03. Which T-code is used to create a Purchase Order?
     A) ME21N
     B) ME51N
     C) ME41
     D) MIRO
     >> CORRECT ANSWER: A) ME21N

Q04. Which T-code is used to display a Purchase Order?
     A) ME22N
     B) ME23N
     C) ME51N
     D) ME11
     >> CORRECT ANSWER: B) ME23N

Q05. Which T-code is used to change a Purchase Order?
     A) ME21N
     B) ME22N
     C) ME23N
     D) ME52N
     >> CORRECT ANSWER: B) ME22N

Q06. Which T-code is used to create an RFQ?
     A) ME41
     B) ME49
     C) ME11
     D) ME01
     >> CORRECT ANSWER: A) ME41

Q07. What is the purpose of an RFQ?
     A) To receive materials
     B) To request price quotations from vendors
     C) To post an invoice
     D) To make payment
     >> CORRECT ANSWER: B) To request price quotations from vendors

Q08. Which T-code is used to compare vendor quotations?
     A) ME41
     B) ME49
     C) ME21N
     D) MIGO
     >> CORRECT ANSWER: B) ME49

Q09. Which T-code is used to create a Purchase Info Record?
     A) ME01
     B) ME11
     C) ME21N
     D) ME51N
     >> CORRECT ANSWER: B) ME11

Q10. What does a Purchase Info Record contain?
     A) Customer information
     B) Material and vendor purchasing information
     C) Employee information
     D) Company code information
     >> CORRECT ANSWER: B) Material and vendor purchasing information

Q11. Which T-code is used to maintain a Source List?
     A) ME01
     B) ME11
     C) ME41
     D) ME49
     >> CORRECT ANSWER: A) ME01

Q12. What is a Purchase Requisition?
     A) Vendor invoice
     B) Internal request to purchase materials or services
     C) Goods receipt
     D) Payment document
     >> CORRECT ANSWER: B) Internal request to purchase materials or services

Q13. What is a Purchase Order?
     A) Internal request
     B) Official purchasing document sent to the vendor
     C) Customer invoice
     D) Goods issue document
     >> CORRECT ANSWER: B) Official purchasing document sent to the vendor

Q14. Which T-code is commonly used for Goods Receipt?
     A) MIRO
     B) MIGO
     C) ME21N
     D) ME51N
     >> CORRECT ANSWER: B) MIGO

Q15. Which movement type is used for standard Goods Receipt against a PO?
     A) 101
     B) 102
     C) 122
     D) 201
     >> CORRECT ANSWER: A) 101

Q16. Which movement type is used to reverse a 101 Goods Receipt?
     A) 102
     B) 101
     C) 122
     D) 161
     >> CORRECT ANSWER: A) 102

Q17. What is Goods Receipt?
     A) Sending materials to vendor
     B) Receiving materials from vendor
     C) Creating a quotation
     D) Making payment
     >> CORRECT ANSWER: B) Receiving materials from vendor

Q18. Which T-code is used for Invoice Verification?
     A) MIGO
     B) MIRO
     C) ME23N
     D) ME51N
     >> CORRECT ANSWER: B) MIRO

Q19. What is a 3-way match?
     A) PR, RFQ and PO
     B) PO, GR and Invoice
     C) PO, Payment and Vendor
     D) PR, GR and Payment
     >> CORRECT ANSWER: B) PO, GR and Invoice

Q20. Which document is normally created after receiving materials?
     A) Goods Receipt document
     B) RFQ
     C) Purchase Requisition
     D) Quotation
     >> CORRECT ANSWER: A) Goods Receipt document

Q21. Who usually provides the quotation?
     A) Customer
     B) Vendor
     C) Employee
     D) Production department
     >> CORRECT ANSWER: B) Vendor

Q22. Which organizational unit is responsible for purchasing activities?
     A) Plant
     B) Purchasing Organization
     C) Storage Location
     D) Company Code
     >> CORRECT ANSWER: B) Purchasing Organization

Q23. What is a Purchasing Group?
     A) Group of materials
     B) Buyer or group of buyers responsible for purchasing
     C) Group of vendors
     D) Group of plants
     >> CORRECT ANSWER: B) Buyer or group of buyers responsible for purchasing

Q24. Which master data contains material information?
     A) Material Master
     B) Vendor Master
     C) Customer Master
     D) Bank Master
     >> CORRECT ANSWER: A) Material Master

Q25. Which master data contains vendor purchasing information?
     A) Material Master
     B) Vendor/Business Partner
     C) Customer Master
     D) Asset Master
     >> CORRECT ANSWER: B) Vendor/Business Partner

Q26. What is a Source List used for?
     A) To identify valid sources/vendors for procurement
     B) To create invoices
     C) To receive materials
     D) To make payments
     >> CORRECT ANSWER: A) To identify valid sources/vendors for procurement

Q27. What is the correct basic P2P sequence?
     A) PO → PR → GR → Invoice
     B) PR → PO → GR → Invoice
     C) GR → PR → PO → Invoice
     D) Invoice → PO → PR → GR
     >> CORRECT ANSWER: B) PR → PO → GR → Invoice

Q28. Which document is sent officially to the vendor to purchase materials?
     A) PR
     B) PO
     C) GR
     D) Invoice
     >> CORRECT ANSWER: B) PO

Q29. Which department is mainly responsible for purchasing activities?
     A) Purchasing/Procurement
     B) Production
     C) Sales
     D) Human Resources
     >> CORRECT ANSWER: A) Purchasing/Procurement

Q30. What is the final stage of the P2P process?
     A) Purchase Requisition
     B) Goods Receipt
     C) Invoice Verification
     D) Vendor Payment
     >> CORRECT ANSWER: D) Vendor Payment
