Q01. What is 15% of 200?
     A) 30
     B) 35
     C) 20
     D) 25
     >> CORRECT ANSWER: A) 30

     A) 140 km
     B) 160 km
     C) 150 km
     D) 120 km
     >> CORRECT ANSWER: C) 150 km

     A) 8 days
     B) 5 days
     C) 7.5 days
     D) 6 days
     >> CORRECT ANSWER: D) 6 days

     B) 15%
     C) 25%

SECTION 2: DATA SCIENCE, MACHINE LEARNING & BUSINESS ANALYTICS (QUESTIONS 21 - 30)
--------------------------------------------------------------------------------
Q21. Which SQL clause is used to aggregate data and summarize groups of rows?
     A) WHERE
     B) DISTINCT
     C) ORDER BY
     D) GROUP BY
     >> CORRECT ANSWER: D) GROUP BY

Q22. Which SQL join returns all rows from the left table, and matched rows from the right table?
     A) FULL OUTER JOIN
     B) LEFT JOIN
     C) INNER JOIN
     D) RIGHT JOIN
     >> CORRECT ANSWER: B) LEFT JOIN

Q23. Which Python library is the core standard for tabular data manipulation and DataFrame operations?
     A) Scrapy
     B) Flask
     C) Matplotlib
     D) Pandas
     >> CORRECT ANSWER: D) Pandas

Q24. Which Python library provides fundamental support for large, multi-dimensional arrays and mathematical functions?
     A) Django
     B) PyPDF
     C) NumPy
     D) BeautifulSoup
     >> CORRECT ANSWER: C) NumPy

Q25. Which measure of central tendency is least sensitive to extreme outliers in a skewed dataset?
     A) Variance
     B) Median
     C) Standard Deviation
     D) Mean
     >> CORRECT ANSWER: B) Median

Q26. Which of the following is an example of a Supervised Machine Learning problem?
     A) Customer market basket clustering without labels
     B) Anomaly detection on unlabelled transactions
     C) Dimensionality reduction with PCA
     D) Customer churn prediction with labeled historical data
     >> CORRECT ANSWER: D) Customer churn prediction with labeled historical data

Q27. In classification model evaluation, what does a Confusion Matrix display?
     A) The distribution of primary keys
     B) The training execution speed per epoch
     C) True Positives, False Positives, True Negatives, and False Negatives
     D) The memory usage of each database query
     >> CORRECT ANSWER: C) True Positives, False Positives, True Negatives, and False Negatives

Q28. In Business Analytics, what does the term KPI represent?
     A) Key Performance Indicator
     B) Key Pricing Increment
     C) Knowledge Programming Interface
     D) Kernel Protocol Index
     >> CORRECT ANSWER: A) Key Performance Indicator

Q29. Which chart type is best suited for showing the distribution and spread of continuous numerical data using quartiles?
     A) Radar chart
     B) Pie chart
     C) Box plot (Box and Whisker)
     D) Donut chart
     >> CORRECT ANSWER: C) Box plot (Box and Whisker)

Q30. Which of the following tools is an industry-standard Business Intelligence (BI) tool for interactive dashboards?
     A) Power BI / Tableau
     B) Git Bash
     C) Notepad++
     D) Postman
     >> CORRECT ANSWER: A) Power BI / Tableau
