Q01. What is 15% of 200?
     A) 20
     B) 25
     C) 30
     D) 35

Q02. If a train travels at 60 km/h, how far will it travel in 2.5 hours?
     A) 120 km
     B) 140 km
     C) 150 km
     D) 160 km
     >> CORRECT ANSWER: C) 150 km

     A) 5 days
     B) 6 days
     C) 7.5 days
     D) 8 days
     >> CORRECT ANSWER: B) 6 days

     A) 20%
     B) 25%
     C) 30%
     D) 15%

SECTION 2: TECHNICAL SPECIALIZATION (QUESTIONS 21 - 30)
--------------------------------------------------------------------------------
Q21. Which SQL clause is used to aggregate data and summarize groups of rows?
     A) ORDER BY
     B) GROUP BY
     C) WHERE
     D) DISTINCT
     >> CORRECT ANSWER: B) GROUP BY

Q22. Which SQL join returns all rows from the left table, and matched rows from the right table?
     A) INNER JOIN
     B) LEFT JOIN
     C) RIGHT JOIN
     D) FULL OUTER JOIN
     >> CORRECT ANSWER: B) LEFT JOIN

Q23. Which Python library is the core standard for tabular data manipulation and DataFrame operations?
     A) Pandas
     B) Matplotlib
     C) Flask
     D) Scrapy
     >> CORRECT ANSWER: A) Pandas

Q24. Which Python library provides fundamental support for large, multi-dimensional arrays and mathematical functions?
     A) NumPy
     B) Django
     C) BeautifulSoup
     D) PyPDF
     >> CORRECT ANSWER: A) NumPy

Q25. Which measure of central tendency is least sensitive to extreme outliers in a skewed dataset?
     A) Mean
     B) Median
     C) Standard Deviation
     D) Variance
     >> CORRECT ANSWER: B) Median

Q26. Which of the following is an example of a Supervised Machine Learning problem?
     A) Customer churn prediction with labeled historical data
     B) Customer market basket clustering without labels
     C) Dimensionality reduction with PCA
     D) Anomaly detection on unlabelled transactions
     >> CORRECT ANSWER: A) Customer churn prediction with labeled historical data

Q27. In classification model evaluation, what does a Confusion Matrix display?
     A) True Positives, False Positives, True Negatives, and False Negatives
     B) The memory usage of each database query
     C) The training execution speed per epoch
     D) The distribution of primary keys
     >> CORRECT ANSWER: A) True Positives, False Positives, True Negatives, and False Negatives

Q28. In Business Analytics, what does the term KPI represent?
     A) Knowledge Programming Interface
     B) Key Performance Indicator
     C) Kernel Protocol Index
     D) Key Pricing Increment
     >> CORRECT ANSWER: B) Key Performance Indicator

Q29. Which chart type is best suited for showing the distribution and spread of continuous numerical data using quartiles?
     A) Pie chart
     B) Box plot (Box and Whisker)
     C) Donut chart
     D) Radar chart
     >> CORRECT ANSWER: B) Box plot (Box and Whisker)

Q30. Which of the following tools is an industry-standard Business Intelligence (BI) tool for interactive dashboards?
     A) Power BI / Tableau
     B) Git Bash
     C) Postman
     D) Notepad++
     >> CORRECT ANSWER: A) Power BI / Tableau
