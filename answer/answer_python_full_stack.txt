Q01. What is 15% of 200?
     A) 30
     B) 35
     C) 20
     D) 25
     >> CORRECT ANSWER: A) 30

Q02. If a train travels at 60 km/h, how far will it travel in 2.5 hours?
     A) 140 km
     B) 160 km
     C) 150 km
     D) 120 km
     >> CORRECT ANSWER: C) 150 km

     A) 8 days
     B) 5 days
     C) 7.5 days
     D) 6 days
     >> CORRECT ANSWER: D) 6 days

     C) 25%

SECTION 2: PYTHON FULL STACK (PYTHON, DJANGO, REST, WEB) (QUESTIONS 21 - 30)
--------------------------------------------------------------------------------
Q21. Which keyword is used to define a function in Python?
     A) function
     B) define
     C) def
     D) fun
     >> CORRECT ANSWER: C) def

Q22. Which of the following data structures in Python is immutable?
     A) Set
     B) Tuple
     C) Dictionary
     D) List
     >> CORRECT ANSWER: B) Tuple

Q23. What will be the output of `[x * 2 for x in [1, 2, 3]]`?
     A) [2, 4, 6]
     B) [1, 4, 9]
     C) Error
     D) [1, 2, 3, 1, 2, 3]
     >> CORRECT ANSWER: A) [2, 4, 6]

Q24. What is the primary role of the `self` parameter in a Python class method?
     A) Creates a static method variable
     B) Import global variables
     C) Refers to the current instance of the class
     D) Refers to the parent class
     >> CORRECT ANSWER: C) Refers to the current instance of the class

Q25. Which keywords are used in Python for structured exception handling?
     A) test / fail
     B) try / catch
     C) do / rescue
     D) try / except
     >> CORRECT ANSWER: D) try / except

Q26. Which widely used Python web framework follows the 'Batteries Included' philosophy with built-in ORM and Admin UI?
     A) Flask
     B) Django
     C) FastAPI
     D) Bottle
     >> CORRECT ANSWER: B) Django

Q27. What is the average time complexity for key lookup in a standard Python dictionary?
     A) O(1)
     B) O(log n)
     C) O(n)
     D) O(n^2)
     >> CORRECT ANSWER: A) O(1)

Q28. In a Full Stack web application, which HTTP method is typically used to update an existing resource idempotently?
     A) DELETE
     B) GET
     C) POST
     D) PUT
     >> CORRECT ANSWER: D) PUT

Q29. What is the purpose of Python's `virtualenv` / `venv` module?
     A) To encrypt source code files
     B) To isolate project-specific Python dependencies and packages
     C) To compile Python into WebAssembly
     D) To run virtual machines for Windows inside Linux
     >> CORRECT ANSWER: B) To isolate project-specific Python dependencies and packages

Q30. In JavaScript frontend development, which method allows selecting a DOM element using a CSS selector?
     A) window.findSelector()
     B) document.getElementByIdOnly()
     C) browser.getDOM()
     D) document.querySelector()
     >> CORRECT ANSWER: D) document.querySelector()
