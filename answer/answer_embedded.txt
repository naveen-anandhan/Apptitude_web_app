SECTION 2: TECHNICAL SPECIALIZATION (QUESTIONS 21 - 30)
--------------------------------------------------------------------------------
Q21. What is the primary architectural difference between a Microcontroller (MCU) and a Microprocessor (MPU)?
     A) An MCU integrates CPU, RAM, ROM, and I/O peripherals onto a single chip
     B) An MPU cannot perform arithmetic calculations
     C) An MCU does not require clock oscillators
     D) An MPU can only execute Python code
     >> CORRECT ANSWER: A) An MCU integrates CPU, RAM, ROM, and I/O peripherals onto a single chip

Q22. Which programming language is predominantly used for low-level firmware and embedded microcontroller development?
     A) C / Embedded C
     B) JavaScript
     C) PHP
     D) Ruby
     >> CORRECT ANSWER: A) C / Embedded C

Q23. What is the primary purpose of an ADC (Analog-to-Digital Converter) in an embedded system?
     A) Converts continuous sensor signals into digital discrete values
     B) Converts DC power into AC power
     C) Amplifies audio sound output
     D) Translates machine code into assembly
     >> CORRECT ANSWER: A) Converts continuous sensor signals into digital discrete values

Q24. What is the role of a Watchdog Timer (WDT) in a microcontroller?
     A) Automatically reset the system if software hangs or enters an infinite loop
     B) Display the current wall clock time on an LCD
     C) Speed up memory reading
     D) Control fan temperature
     >> CORRECT ANSWER: A) Automatically reset the system if software hangs or enters an infinite loop

Q25. Which synchronous serial communication protocol uses MOSI, MISO, SCK, and CS/SS lines?
     A) SPI
     B) I2C
     C) UART
     D) RS-232
     >> CORRECT ANSWER: A) SPI

Q26. How many signal lines does the I2C bus protocol fundamentally require for communication?
     A) 2 (SDA and SCL)
     B) 4 (MOSI, MISO, SCK, CS)
     C) 8 (Data byte bus)
     D) 1 (Single wire only)
     >> CORRECT ANSWER: A) 2 (SDA and SCL)

Q27. What does ISR stand for in embedded event handling?
     A) Interrupt Service Routine
     B) Internal System Register
     C) Instruction Set Reader
     D) Input Signal Router
     >> CORRECT ANSWER: A) Interrupt Service Routine

Q28. What does PWM stand for, and what is its common application in embedded control?
     A) Pulse Width Modulation; used for controlling motor speeds and LED brightness
     B) Power Wave Monitor; used to check battery voltage
     C) Program Word Memory; used for flashing bootloaders
     D) Periodic Wave Multiplier; used for clock division
     >> CORRECT ANSWER: A) Pulse Width Modulation; used for controlling motor speeds and LED brightness

Q29. What is the key characteristic of a Real-Time Operating System (RTOS)?
     A) Predictable and deterministic task execution within strict deadlines
     B) A visually appealing graphical desktop interface
     C) Unlimited background process multitasking without priorities
     D) Requirement of at least 8 GB of RAM
     >> CORRECT ANSWER: A) Predictable and deterministic task execution within strict deadlines

Q30. What does GPIO stand for on a development board or microcontroller?
     A) General Purpose Input/Output
     B) Graphics Processing Interface Output
     C) Global Protocol Input Operation
     D) Generic Port Interconnect Option
     >> CORRECT ANSWER: A) General Purpose Input/Output
