SECTION 2: TECHNICAL SPECIALIZATION (QUESTIONS 21 - 30)
--------------------------------------------------------------------------------
Q21. What is the primary architectural difference between a Microcontroller (MCU) and a Microprocessor (MPU)?
     A) An MCU integrates CPU, RAM, ROM, and I/O peripherals onto a single chip
     B) An MPU can only execute Python code
     C) An MPU cannot perform arithmetic calculations
     D) An MCU does not require clock oscillators
     >> CORRECT ANSWER: A) An MCU integrates CPU, RAM, ROM, and I/O peripherals onto a single chip

Q22. Which programming language is predominantly used for low-level firmware and embedded microcontroller development?
     A) Ruby
     B) C / Embedded C
     C) JavaScript
     D) PHP
     >> CORRECT ANSWER: B) C / Embedded C

Q23. What is the primary purpose of an ADC (Analog-to-Digital Converter) in an embedded system?
     A) Translates machine code into assembly
     B) Converts DC power into AC power
     C) Amplifies audio sound output
     D) Converts continuous sensor signals into digital discrete values
     >> CORRECT ANSWER: D) Converts continuous sensor signals into digital discrete values

Q24. What is the role of a Watchdog Timer (WDT) in a microcontroller?
     A) Display the current wall clock time on an LCD
     B) Control fan temperature
     C) Automatically reset the system if software hangs or enters an infinite loop
     D) Speed up memory reading
     >> CORRECT ANSWER: C) Automatically reset the system if software hangs or enters an infinite loop

Q25. Which synchronous serial communication protocol uses MOSI, MISO, SCK, and CS/SS lines?
     A) I2C
     B) RS-232
     C) UART
     D) SPI
     >> CORRECT ANSWER: D) SPI

Q26. How many signal lines does the I2C bus protocol fundamentally require for communication?
     A) 8 (Data byte bus)
     B) 2 (SDA and SCL)
     C) 4 (MOSI, MISO, SCK, CS)
     D) 1 (Single wire only)
     >> CORRECT ANSWER: B) 2 (SDA and SCL)

Q27. What does ISR stand for in embedded event handling?
     A) Instruction Set Reader
     B) Internal System Register
     C) Interrupt Service Routine
     D) Input Signal Router
     >> CORRECT ANSWER: C) Interrupt Service Routine

Q28. What does PWM stand for, and what is its common application in embedded control?
     A) Program Word Memory; used for flashing bootloaders
     B) Pulse Width Modulation; used for controlling motor speeds and LED brightness
     C) Periodic Wave Multiplier; used for clock division
     D) Power Wave Monitor; used to check battery voltage
     >> CORRECT ANSWER: B) Pulse Width Modulation; used for controlling motor speeds and LED brightness

Q29. What is the key characteristic of a Real-Time Operating System (RTOS)?
     A) Predictable and deterministic task execution within strict deadlines
     B) Unlimited background process multitasking without priorities
     C) Requirement of at least 8 GB of RAM
     D) A visually appealing graphical desktop interface
     >> CORRECT ANSWER: A) Predictable and deterministic task execution within strict deadlines

Q30. What does GPIO stand for on a development board or microcontroller?
     A) General Purpose Input/Output
     B) Generic Port Interconnect Option
     C) Graphics Processing Interface Output
     D) Global Protocol Input Operation
     >> CORRECT ANSWER: A) General Purpose Input/Output
