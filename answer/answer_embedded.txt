SECTION 2: EMBEDDED SYSTEMS & MICROCONTROLLER ARCHITECTURE (QUESTIONS 21 - 30)
--------------------------------------------------------------------------------
Q21. What is the primary architectural difference between a Microcontroller (MCU) and a Microprocessor (MPU)?
     A) An MPU can only execute Python code
     B) An MCU does not require clock oscillators
     C) An MCU integrates CPU, RAM, ROM, and I/O peripherals onto a single chip
     D) An MPU cannot perform arithmetic calculations
     >> CORRECT ANSWER: C) An MCU integrates CPU, RAM, ROM, and I/O peripherals onto a single chip

Q22. Which programming language is predominantly used for low-level firmware and embedded microcontroller development?
     A) Ruby
     B) JavaScript
     C) PHP
     D) C / Embedded C
     >> CORRECT ANSWER: D) C / Embedded C

Q23. What is the primary purpose of an ADC (Analog-to-Digital Converter) in an embedded system?
     A) Translates machine code into assembly
     B) Converts DC power into AC power
     C) Converts continuous sensor signals into digital discrete values
     D) Amplifies audio sound output
     >> CORRECT ANSWER: C) Converts continuous sensor signals into digital discrete values

Q24. What is the role of a Watchdog Timer (WDT) in a microcontroller?
     A) Automatically reset the system if software hangs or enters an infinite loop
     B) Control fan temperature
     C) Speed up memory reading
     D) Display the current wall clock time on an LCD
     >> CORRECT ANSWER: A) Automatically reset the system if software hangs or enters an infinite loop

Q25. Which synchronous serial communication protocol uses MOSI, MISO, SCK, and CS/SS lines?
     A) I2C
     B) RS-232
     C) UART
     D) SPI
     >> CORRECT ANSWER: D) SPI

Q26. How many signal lines does the I2C bus protocol fundamentally require for communication?
     A) 1 (Single wire only)
     B) 2 (SDA and SCL)
     C) 4 (MOSI, MISO, SCK, CS)
     D) 8 (Data byte bus)
     >> CORRECT ANSWER: B) 2 (SDA and SCL)

Q27. What does ISR stand for in embedded event handling?
     A) Input Signal Router
     B) Internal System Register
     C) Instruction Set Reader
     D) Interrupt Service Routine
     >> CORRECT ANSWER: D) Interrupt Service Routine

Q28. What does PWM stand for, and what is its common application in embedded control?
     A) Pulse Width Modulation; used for controlling motor speeds and LED brightness
     B) Program Word Memory; used for flashing bootloaders
     C) Periodic Wave Multiplier; used for clock division
     D) Power Wave Monitor; used to check battery voltage
     >> CORRECT ANSWER: A) Pulse Width Modulation; used for controlling motor speeds and LED brightness

Q29. What is the key characteristic of a Real-Time Operating System (RTOS)?
     A) Requirement of at least 8 GB of RAM
     B) Predictable and deterministic task execution within strict deadlines
     C) A visually appealing graphical desktop interface
     D) Unlimited background process multitasking without priorities
     >> CORRECT ANSWER: B) Predictable and deterministic task execution within strict deadlines

Q30. What does GPIO stand for on a development board or microcontroller?
     A) General Purpose Input/Output
     B) Global Protocol Input Operation
     C) Graphics Processing Interface Output
     D) Generic Port Interconnect Option
     >> CORRECT ANSWER: A) General Purpose Input/Output
