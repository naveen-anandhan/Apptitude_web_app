Q01. What is 15% of 200?
     A) 30
     B) 20
     C) 35

     B) 120 km
     C) 160 km
     D) 140 km
     >> CORRECT ANSWER: A) 150 km

     A) 7.5 days

SECTION 2: TECHNICAL SPECIALIZATION (QUESTIONS 21 - 30)
--------------------------------------------------------------------------------
Q21. Which method serves as the standard entry point for running any Java standalone application?
     A) public void main()
     B) static boolean run(String args)
     C) public static void main(String[] args)
     D) public abstract int start()
     >> CORRECT ANSWER: C) public static void main(String[] args)

Q22. Which Java keyword is used to inherit properties and methods from a superclass?
     A) inherits
     B) super
     C) implements
     D) extends
     >> CORRECT ANSWER: D) extends

Q23. What is the key difference between String `==` and String `.equals()` in Java?
     A) Both perform exact identical checks
     B) `==` is used for numbers, `.equals()` can only be used on primitives
     C) `.equals()` compares memory reference, while `==` compares contents
     D) `==` compares memory reference, while `.equals()` compares character contents
     >> CORRECT ANSWER: D) `==` compares memory reference, while `.equals()` compares character contents

Q24. How does Java automatically manage memory deallocation for objects no longer in use?
     A) Operating system paging
     B) Garbage Collector (GC)
     C) Destructors in every class
     D) Manual `free()` statements
     >> CORRECT ANSWER: B) Garbage Collector (GC)

Q25. Which Java Collection interface stores unique elements and does not permit duplicates?
     A) Set
     B) ArrayList
     C) List
     D) Queue
     >> CORRECT ANSWER: A) Set

Q26. In Spring Boot, which annotation is typically placed at the class level to create a RESTful controller returning JSON?
     A) @Repository
     B) @Service
     C) @RestController
     D) @Controller
     >> CORRECT ANSWER: C) @RestController

Q27. What does the `final` keyword indicate when applied to a Java class?
     A) The class cannot be subclassed (inherited)
     B) The class will be deleted after execution
     C) The class contains only static methods
     D) The class cannot be instantiated
     >> CORRECT ANSWER: A) The class cannot be subclassed (inherited)

Q28. What does JPA stand for in Java enterprise database persistence?
     A) Joint Protocol Adapter
     B) Java Persistence API
     C) Java Program Application
     D) Java Process Automation
     >> CORRECT ANSWER: B) Java Persistence API

Q29. Which HTTP status code signifies that a resource was successfully created on the server?
     A) 201 Created
     B) 301 Moved
     C) 204 No Content
     D) 200 OK
     >> CORRECT ANSWER: A) 201 Created

Q30. Which build tool is widely used for dependency management and build automation in modern Java projects?
     A) Pip
     B) Maven / Gradle
     C) Webpack
     D) Composer
     >> CORRECT ANSWER: B) Maven / Gradle
