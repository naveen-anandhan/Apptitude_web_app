SECTION 2: JAVA FULL STACK DEVELOPMENT SPECIALIZATION (QUESTIONS 21 - 30)
--------------------------------------------------------------------------------
Q21. Which method serves as the standard entry point for running any Java standalone application?
     A) public void main()
     B) public static void main(String[] args)
     C) public abstract int start()
     D) static boolean run(String args)
     >> CORRECT ANSWER: B) public static void main(String[] args)

Q22. Which Java keyword is used to inherit properties and methods from a superclass?
     A) implements
     B) extends
     C) inherits
     D) super
     >> CORRECT ANSWER: B) extends

Q23. What is the key difference between String `==` and String `.equals()` in Java?
     A) `==` compares memory reference, while `.equals()` compares character contents
     B) `.equals()` compares memory reference, while `==` compares contents
     C) Both perform exact identical checks
     D) `==` is used for numbers, `.equals()` can only be used on primitives
     >> CORRECT ANSWER: A) `==` compares memory reference, while `.equals()` compares character contents

Q24. How does Java automatically manage memory deallocation for objects no longer in use?
     A) Manual `free()` statements
     B) Garbage Collector (GC)
     C) Destructors in every class
     D) Operating system paging
     >> CORRECT ANSWER: B) Garbage Collector (GC)

Q25. Which Java Collection interface stores unique elements and does not permit duplicates?
     A) List
     B) Set
     C) Queue
     D) ArrayList
     >> CORRECT ANSWER: B) Set

Q26. In Spring Boot, which annotation is typically placed at the class level to create a RESTful controller returning JSON?
     A) @Controller
     B) @RestController
     C) @Service
     D) @Repository
     >> CORRECT ANSWER: B) @RestController

Q27. What does the `final` keyword indicate when applied to a Java class?
     A) The class cannot be instantiated
     B) The class cannot be subclassed (inherited)
     C) The class contains only static methods
     D) The class will be deleted after execution
     >> CORRECT ANSWER: B) The class cannot be subclassed (inherited)

Q28. What does JPA stand for in Java enterprise database persistence?
     A) Java Persistence API
     B) Java Process Automation
     C) Joint Protocol Adapter
     D) Java Program Application
     >> CORRECT ANSWER: A) Java Persistence API

Q29. Which HTTP status code signifies that a resource was successfully created on the server?
     A) 200 OK
     B) 201 Created
     C) 204 No Content
     D) 301 Moved
     >> CORRECT ANSWER: B) 201 Created

Q30. Which build tool is widely used for dependency management and build automation in modern Java projects?
     A) Maven / Gradle
     B) Webpack
     C) Pip
     D) Composer
     >> CORRECT ANSWER: A) Maven / Gradle
