Q01. What is 15% of 200?
     A) 30
     B) 20
     C) 35
     D) 25
     >> CORRECT ANSWER: A) 30

Q02. If a train travels at 60 km/h, how far will it travel in 2.5 hours?
     A) 150 km
     B) 120 km
     C) 160 km
     D) 140 km
     >> CORRECT ANSWER: A) 150 km

Q03. If A can complete a work in 10 days and B in 15 days, how many days will they take working together?
     A) 7.5 days
     B) 5 days
     C) 6 days
     D) 8 days
     >> CORRECT ANSWER: C) 6 days

Q04. A shopkeeper buys an item for ₹400 and sells it for ₹500. What is the profit percentage?
     A) 20%
     B) 30%
     C) 25%
     D) 15%
     >> CORRECT ANSWER: C) 25%

Q05. The ratio of two numbers is 3:5 and their sum is 80. What is the smaller number?
     A) 36
     B) 30
     C) 32
     D) 24
     >> CORRECT ANSWER: B) 30

Q06. Find the simple interest on ₹5,000 at 6% per annum for 2 years.
     A) ₹500
     B) ₹650
     C) ₹600
     D) ₹550
     >> CORRECT ANSWER: C) ₹600

Q07. The average of five numbers is 20. If one number is removed, the average becomes 18. What was the removed number?
     A) 30
     B) 28
     C) 26
     D) 24
     >> CORRECT ANSWER: B) 28

Q08. Find the next number in the sequence: 3, 6, 12, 24, 48, ?
     A) 108
     B) 84
     C) 72
     D) 96
     >> CORRECT ANSWER: D) 96

Q09. Find the next number in the sequence: 2, 5, 10, 17, 26, ?
     A) 37
     B) 35
     C) 41
     D) 39
     >> CORRECT ANSWER: A) 37

Q10. If 'LIGHT' is coded as 'MTHIU', how is 'PLANT' coded following the same pattern?
     A) QMBOU
     B) QMANS
     C) QMBNU
     D) QNCPO
     >> CORRECT ANSWER: A) QMBOU

Q11. Pointing to a photograph, a man said: 'She is the daughter of my father's only son.' How is the girl related to the man?
     A) Sister
     B) Niece
     C) Mother
     D) Daughter
     >> CORRECT ANSWER: D) Daughter

Q12. A person walks 10 meters North, turns right and walks 10 meters, then turns right and walks 10 meters. In which direction is he from the starting point?
     A) South
     B) East
     C) West
     D) North
     >> CORRECT ANSWER: B) East

Q13. Which word does NOT belong with the others?
     A) Inch
     B) Ounce
     C) Centimeter
     D) Yard
     >> CORRECT ANSWER: B) Ounce

Q14. Choose the correct synonym for 'CANDID':
     A) Frank and honest
     B) Secretive
     C) Fearful
     D) Dishonest
     >> CORRECT ANSWER: A) Frank and honest

Q15. Choose the correctly spelled word:
     A) Occurrence
     B) Occurence
     C) Ocurrence
     D) Occurrance
     >> CORRECT ANSWER: A) Occurrence

Q16. What is the primary function of RAM in a computer?
     A) Cooling the motherboard
     B) Permanent data storage
     C) Temporary volatile storage for active processes
     D) Power regulation
     >> CORRECT ANSWER: C) Temporary volatile storage for active processes

Q17. Which of the following is an Operating System?
     A) Adobe Acrobat
     B) Google Chrome
     C) Oracle SQL
     D) Linux
     >> CORRECT ANSWER: D) Linux

Q18. What does HTTP stand for?
     A) HyperTransfer Terminal Protocol
     B) HyperText Transfer Protocol
     C) HomeText Translation Process
     D) HighText Transmission Program
     >> CORRECT ANSWER: B) HyperText Transfer Protocol

Q19. How many bits are there in 1 Byte?
     A) 16
     B) 4
     C) 8
     D) 32
     >> CORRECT ANSWER: C) 8

Q20. In a flowchart, which geometric symbol is used to represent a decision/condition?
     A) Rectangle
     B) Diamond
     C) Oval
     D) Parallelogram
     >> CORRECT ANSWER: B) Diamond

SECTION 2: TECHNICAL SPECIALIZATION (QUESTIONS 21 - 30)
--------------------------------------------------------------------------------
Q21. What does SAP stand for?
     A) Systems, Applications and Products in Data Processing
     B) System Analysis Program
     C) System Application and Products
     D) Software Application Program
     >> CORRECT ANSWER: A) Systems, Applications and Products in Data Processing

Q22. Which SAP module is primarily responsible for Financial Accounting?
     A) FI
     B) PP
     C) SD
     D) MM
     >> CORRECT ANSWER: A) FI

Q23. Which SAP module manages purchasing, inventory management, and invoice verification?
     A) SD
     B) CO
     C) QM
     D) MM
     >> CORRECT ANSWER: D) MM

Q24. Which SAP module covers customer order processing, shipping, and billing?
     A) PM
     B) PS
     C) MM
     D) SD
     >> CORRECT ANSWER: D) SD

Q25. What is SAP HANA primarily characterized as?
     A) An operating system for mainframes
     B) An in-memory, column-oriented relational database management system
     C) An email client application
     D) A web design framework
     >> CORRECT ANSWER: B) An in-memory, column-oriented relational database management system

Q26. What is the primary purpose of a Transaction Code (T-Code) in SAP GUI?
     A) A keyboard shortcut to navigate directly to an application screen or task
     B) A password reset code for users
     C) A barcode scanner setting
     D) An encrypted database license key
     >> CORRECT ANSWER: A) A keyboard shortcut to navigate directly to an application screen or task

Q27. What programming language is predominantly used to develop business applications within the SAP environment?
     A) Python
     B) C#
     C) ABAP
     D) Swift
     >> CORRECT ANSWER: C) ABAP

Q28. In SAP, what does the ERP acronym represent?
     A) Extensible Reporting Platform
     B) Enterprise Resource Planning
     C) Electronic Record Processing
     D) Entity Relationship Protocol
     >> CORRECT ANSWER: B) Enterprise Resource Planning

Q29. Which SAP module is designed for controlling internal cost and managerial reporting?
     A) SD
     B) CO
     C) FI
     D) HR
     >> CORRECT ANSWER: B) CO

Q30. What is the organizational level in SAP representing an independent legal accounting entity?
     A) Plant
     B) Storage Location
     C) Company Code
     D) Sales Organization
     >> CORRECT ANSWER: C) Company Code
