## Quality & Anti-Cheat Guarantees
- **No Answer Streaks / Zero Adjacent Duplicates**: No two consecutive questions share the same correct option letter (`ans[i] != ans[i-1]` across all 30 questions).
- **Balanced Distribution**: Across every 30-question assessment, each option (A, B, C, D) appears approximately 7 to 8 times (~25% each).
- **Synchronized**: All answer keys 100% match the live questions served by Firebase Firestore.
