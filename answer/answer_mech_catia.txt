Q01. Which aerospace and engineering corporation is the original developer and publisher of CATIA?
     A) Dassault Systèmes
     B) Siemens Digital Industries
     C) PTC
     D) Autodesk
     >> CORRECT ANSWER: A) Dassault Systèmes

Q02. In CATIA V5, what is the specialized working environment tailored for a specific engineering task (e.g., Part Design, Drafting) called?
     A) Dashboard
     B) Canvas
     C) Viewport
     D) Workbench
     >> CORRECT ANSWER: D) Workbench

Q03. Which workbench in CATIA V5 is primarily utilized for creating 3D parametric mechanical solid parts?
     A) Drafting
     B) Generative Shape Design
     C) Part Design
     D) DMU Kinematics
     >> CORRECT ANSWER: C) Part Design

Q04. In CATIA Sketcher, what does a GREEN color on a 2D profile indicate during geometry diagnostics?
     A) The geometry is under-constrained
     B) The geometry is fully constrained (iso-constrained)
     C) The geometry is over-constrained with conflicting dimensions
     D) The geometry is disconnected or unclosed
     >> CORRECT ANSWER: B) The geometry is fully constrained (iso-constrained)

Q05. In CATIA Sketcher, what does a WHITE color on a line or arc indicate?
     A) The element is under-constrained (has remaining degrees of freedom)
     B) The element is in error and cannot be extruded
     C) The element is fully fixed in space
     D) The element is a construction reference line
     >> CORRECT ANSWER: A) The element is under-constrained (has remaining degrees of freedom)

Q06. In CATIA Sketcher, what does a PURPLE / MAGENTA or RED color on a sketch indicate?
     A) A mirrored profile
     B) Over-constrained geometry (too many conflicting dimensions/constraints)
     C) Active construction geometry
     D) A profile ready for immediate Pad creation
     >> CORRECT ANSWER: B) Over-constrained geometry (too many conflicting dimensions/constraints)

Q07. In CATIA Part Design, which command is used to linearly extrude a 2D closed sketch into a 3D solid body?
     A) Pad
     B) Shaft
     C) Pocket
     D) Rib
     >> CORRECT ANSWER: A) Pad

Q08. In CATIA Part Design, which command creates a solid of revolution by revolving a 2D profile around a specified axis?
     A) Slot
     B) Shaft
     C) Groove
     D) Pad
     >> CORRECT ANSWER: B) Shaft

Q09. In CATIA Part Design, which command removes material by extruding a 2D profile into an existing solid feature?
     A) Pocket
     B) Hole
     C) Multi-sections Solid
     D) Pad
     >> CORRECT ANSWER: A) Pocket

Q10. In CATIA Part Design, which command is the material-removal counterpart to the Shaft tool (revolving cut)?
     A) Fillet
     B) Pocket
     C) Groove
     D) Draft
     >> CORRECT ANSWER: C) Groove

Q11. What is the key advantage of using a 'Positioned Sketch' over a standard 'Sketch' in CATIA?
     A) Reduces the file size of the 3D model by 50%
     B) Locks the sketch so no dimensions are required
     C) Automatically converts lines into 3D solids without padding
     D) Allows precise definition of the sketch origin point and orientation axes (H and V)
     >> CORRECT ANSWER: D) Allows precise definition of the sketch origin point and orientation axes (H and V)

Q12. In CATIA Part Design, which command is used to sweep a planar profile along an open or closed center curve trajectory?
     A) Pad
     B) Rib
     C) Pocket
     D) Slot
     >> CORRECT ANSWER: B) Rib

Q13. Which CATIA Part Design command removes material by sweeping a profile along a center guide curve?
     A) Shaft
     B) Rib
     C) Slot
     D) Chamfer
     >> CORRECT ANSWER: C) Slot

Q14. In CATIA Part Design, which feature creates a complex transitional solid connecting multiple cross-sectional planar sketches (similar to a Loft)?
     A) Shaft
     B) Pad
     C) Stiffener
     D) Multi-sections Solid
     >> CORRECT ANSWER: D) Multi-sections Solid

Q15. Which dress-up feature in CATIA Part Design is used to smooth sharp edges with a uniform circular radius?
     A) Shell
     B) Chamfer
     C) Edge Fillet
     D) Draft
     >> CORRECT ANSWER: C) Edge Fillet

Q16. In CATIA Part Design, what parameters are required when applying a 'Draft Angle' feature?
     A) Faces to draft, Angle, Neutral Element, and Pulling Direction
     B) Material density and Young's modulus
     C) Coordinate origin and bounding box limits
     D) Tool spindle speed and feed rate

Q17. Which feature in CATIA Part Design hollows out a solid component, leaving a specified default wall thickness?
     A) Pocket
     B) Shell
     C) Mirror
     D) Stiffener

Q18. Which feature in CATIA Part Design is specifically designed to create web stiffening ribs from an open 2D sketch profile?
     A) Rib
     B) Shaft
     C) Stiffener
     D) Pad
     >> CORRECT ANSWER: C) Stiffener

Q19. What operations are available under Boolean Operations in CATIA Part Design when combining multiple solid bodies?
     A) Assemble, Add, Remove, and Intersect
     B) Compile, Link, Debug, and Run
     C) Copy, Cut, Paste, and Delete
     D) Extrude, Revolve, Sweep, and Blend

Q23. In the CATIA Specification Tree, what does selecting 'Define in Work Object' on a feature do?
