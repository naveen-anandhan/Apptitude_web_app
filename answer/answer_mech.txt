--------------------------------------------------------------------------------
Q01. What is PTC Creo primarily categorized as in engineering design?
     A) Operating system kernel utility
     B) Parametric 3D CAD / CAM / CAE modeling software
     C) Relational Database Management System
     D) Vector graphic illustration software
     >> CORRECT ANSWER: B) Parametric 3D CAD / CAM / CAE modeling software

Q02. In Creo Sketcher, what is the key difference between 'Weak' and 'Strong' dimensions?
     A) Weak dimensions are measured in inches; Strong dimensions are measured in millimeters
     B) Weak dimensions apply only to 3D solids; Strong dimensions apply to 2D sketches
     C) Weak dimensions are automatically generated by the Intent Manager; Strong dimensions are explicitly defined or modified by the user
     D) Weak dimensions cannot be seen on screen; Strong dimensions are always visible
     >> CORRECT ANSWER: C) Weak dimensions are automatically generated by the Intent Manager; Strong dimensions are explicitly defined or modified by the user

Q03. Which tool in Creo is used to create a 3D solid by linearly projecting a 2D sketch perpendicular to the sketch plane?
     A) Sweep
     B) Extrude
     C) Revolve
     D) Blend
     >> CORRECT ANSWER: B) Extrude

Q04. What essential geometric reference is mandatory when creating a solid feature using the 'Revolve' tool in Creo?
     A) A spherical datum coordinate
     B) A helical trajectory curve
     C) A centerline / Axis of revolution
     D) A chamfer vertex point
     >> CORRECT ANSWER: C) A centerline / Axis of revolution

Q05. What is the primary function of a 'Datum Plane' in Creo parametric modeling?
     A) Defines the raw material cost of the component
     B) Serves as a reference plane for sketching, dimensioning, and feature placement
     C) Specifies the thermal conductivity of the alloy
     D) Renders photorealistic raytraced textures
     >> CORRECT ANSWER: B) Serves as a reference plane for sketching, dimensioning, and feature placement

Q06. Which tool in Creo creates a solid feature by sweeping a planar cross-section along an open or closed trajectory path?
     A) Shell
     B) Hole
     C) Extrude
     D) Sweep
     >> CORRECT ANSWER: D) Sweep

Q07. What is the engineering purpose of applying a 'Round' (Fillet) to the re-entrant corners of a mechanical part?
     A) To reduce stress concentrations and eliminate notch effects
     B) To speed up 3D printing slicing
     C) To increase the structural weight of the casting
     D) To make the CAD file size smaller
     >> CORRECT ANSWER: A) To reduce stress concentrations and eliminate notch effects

Q08. Which dimension scheme option is available when defining a standard 'Chamfer' in Creo?
     A) Diameter x Pitch only
     B) 45 x D, D x D, D1 x D2, and Angle x D
     C) Volume x Density
     D) Radius x Arc Length only
     >> CORRECT ANSWER: B) 45 x D, D x D, D1 x D2, and Angle x D

Q09. In Creo, which feature is used to hollow out the interior of a solid body while maintaining specified wall thickness?
     A) Shell
     B) Rib
     C) Draft
     D) Mirror
     >> CORRECT ANSWER: A) Shell

Q10. Why is a 'Draft' feature applied to faces of components designed for plastic injection molding or metal casting?
     A) To increase the hardness of the plastic resin
     B) To prevent oxidation of the mold steel
     C) To convert 3D geometry into 2D drawing lines
     D) To provide a taper angle allowing easy ejection of the part from the mold
     >> CORRECT ANSWER: D) To provide a taper angle allowing easy ejection of the part from the mold

Q11. Which Creo feature is specifically engineered for adding structural stiffening webs between intersecting walls?
     A) Datum Axis
     B) Extrude Cut
     C) Rib (Profile Rib / Trajectory Rib)
     D) Chamfer
     >> CORRECT ANSWER: C) Rib (Profile Rib / Trajectory Rib)

Q12. What are the standard hole creation types provided by the Creo 'Hole' tool?
     A) Magnetic and Hydraulic
     B) Simple, Standard (Threaded/Clearance), and Sketched
     C) Punched and Laser cut only
     D) Square, Hexagonal, and Octagonal only
     >> CORRECT ANSWER: B) Simple, Standard (Threaded/Clearance), and Sketched

Q13. Which pattern type in Creo allows replicating features radially around a central cylindrical axis?
     A) Fill Pattern
     B) Table Pattern
     C) Direction Pattern
     D) Axis Pattern
     >> CORRECT ANSWER: D) Axis Pattern

Q14. In Creo, what capability do 'Relations' (Tools > Relations) provide in parametric modeling?
     A) Mathematical equations that drive dimensions based on other dimensions or parameters
     B) Email notifications when a file is saved
     C) Bluetooth connections to CNC machines
     D) Automatic color grading of 3D models
     >> CORRECT ANSWER: A) Mathematical equations that drive dimensions based on other dimensions or parameters

Q15. What is a 'Family Table' in Creo used for?
     A) Managing user accounts and employee salaries
     B) Arranging color palettes in the rendering module
     C) Generating a collection of similar parts (instances) derived from a single generic model
     D) Organizing computer hard drive directories
     >> CORRECT ANSWER: C) Generating a collection of similar parts (instances) derived from a single generic model

Q16. In Creo Assembly, which constraint aligns two planar faces so that their normal vectors point in opposite directions and touch?
     A) Align
     B) Mate
     C) Orient
     D) Insert
     >> CORRECT ANSWER: B) Mate

Q17. Which Creo Assembly constraint is commonly used to assemble a bolt or pin into a cylindrical hole in one step?
     A) Insert
     B) Tangent
     C) Fix
     D) Parallel
     >> CORRECT ANSWER: A) Insert

Q18. In Creo Mechanism Design, which connection joint allows pure rotational movement around a single axis (1 degree of freedom)?
     A) Slider joint
     B) Ball joint
     C) Cylinder joint
     D) Pin joint
     >> CORRECT ANSWER: D) Pin joint

Q19. What tool in Creo Assembly is utilized to identify physical overlapping between neighboring solid components?
     A) Explode State animation
     B) Bill of Materials

     D) Global Interference / Clash Check
     >> CORRECT ANSWER: D) Global Interference / Clash Check

Q20. In Creo Sheetmetal design, what parameter represents the ratio of the neutral axis position to the sheet metal thickness during bending?
     A) Poisson's Ratio
     B) Shear Modulus
     C) K-Factor
     D) Young's Modulus
     >> CORRECT ANSWER: C) K-Factor

     B) .prt
     C) .frm
     D) .drw
     >> CORRECT ANSWER: A) .asm

Q24. How does Creo handle file versioning when saving a model repeatedly (e.g., saving `bracket.prt`)?
     A) Renames the file to read-only
     B) Compresses the file into a zip archive
     C) Appends an incremental version number extension (e.g., `bracket.prt.1`, `bracket.prt.2`)
     D) Overwrites the previous file with no backup
     >> CORRECT ANSWER: C) Appends an incremental version number extension (e.g., `bracket.prt.1`, `bracket.prt.2`)

Q25. In Creo Drawing (.drw), what functionality is used to automatically generate an associative Bill of Materials (BOM) table?
     A) Repeat Region in Table
     B) Screenshot paste
     C) Manual text typing

     >> CORRECT ANSWER: A) Repeat Region in Table

Q26. In engineering drawings, what does a 'Section View' reveal that is not visible in standard exterior projection views?
     A) The total shipping package dimensions

     D) The external surface finish color
     >> CORRECT ANSWER: B) Internal geometry, ribs, holes, and wall thicknesses along a cutting plane

Q27. In GD&T, what symbol represents the tolerance zone within which the axis of a cylindrical feature must lie relative to datum references?

     B) Profile of a line
     C) Straightness
     D) Position (True Position)

     >> CORRECT ANSWER: C) Constraints (supports) and Loads (forces/pressures)
