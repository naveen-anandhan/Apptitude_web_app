QUESTIONS 01 - 30: MECHANICAL ENGINEERING - CREO (PTC CREO 3D CAD)
--------------------------------------------------------------------------------
Q01. What is PTC Creo primarily categorized as in engineering design?
     A) Parametric 3D CAD / CAM / CAE modeling software
     B) Relational Database Management System
     C) Vector graphic illustration software
     D) Operating system kernel utility
     >> CORRECT ANSWER: A) Parametric 3D CAD / CAM / CAE modeling software

Q02. In Creo Sketcher, what is the key difference between 'Weak' and 'Strong' dimensions?
     A) Weak dimensions are automatically generated by the Intent Manager; Strong dimensions are explicitly defined or modified by the user
     B) Weak dimensions are measured in inches; Strong dimensions are measured in millimeters
     C) Weak dimensions cannot be seen on screen; Strong dimensions are always visible
     D) Weak dimensions apply only to 3D solids; Strong dimensions apply to 2D sketches
     >> CORRECT ANSWER: A) Weak dimensions are automatically generated by the Intent Manager; Strong dimensions are explicitly defined or modified by the user

Q03. Which tool in Creo is used to create a 3D solid by linearly projecting a 2D sketch perpendicular to the sketch plane?
     A) Extrude
     B) Revolve
     C) Sweep
     D) Blend
     >> CORRECT ANSWER: A) Extrude

Q04. What essential geometric reference is mandatory when creating a solid feature using the 'Revolve' tool in Creo?
     A) A centerline / Axis of revolution
     B) A spherical datum coordinate
     C) A helical trajectory curve
     D) A chamfer vertex point
     >> CORRECT ANSWER: A) A centerline / Axis of revolution

Q05. What is the primary function of a 'Datum Plane' in Creo parametric modeling?
     A) Serves as a reference plane for sketching, dimensioning, and feature placement
     B) Defines the raw material cost of the component
     C) Specifies the thermal conductivity of the alloy
     D) Renders photorealistic raytraced textures
     >> CORRECT ANSWER: A) Serves as a reference plane for sketching, dimensioning, and feature placement

Q06. Which tool in Creo creates a solid feature by sweeping a planar cross-section along an open or closed trajectory path?
     A) Sweep
     B) Extrude
     C) Hole
     D) Shell
     >> CORRECT ANSWER: A) Sweep

Q07. What is the engineering purpose of applying a 'Round' (Fillet) to the re-entrant corners of a mechanical part?
     A) To reduce stress concentrations and eliminate notch effects
     B) To increase the structural weight of the casting
     C) To make the CAD file size smaller
     D) To speed up 3D printing slicing
     >> CORRECT ANSWER: A) To reduce stress concentrations and eliminate notch effects

Q08. Which dimension scheme option is available when defining a standard 'Chamfer' in Creo?
     A) 45 x D, D x D, D1 x D2, and Angle x D
     B) Radius x Arc Length only
     C) Diameter x Pitch only
     D) Volume x Density
     >> CORRECT ANSWER: A) 45 x D, D x D, D1 x D2, and Angle x D

Q09. In Creo, which feature is used to hollow out the interior of a solid body while maintaining specified wall thickness?
     A) Shell
     B) Rib
     C) Draft
     D) Mirror
     >> CORRECT ANSWER: A) Shell

Q10. Why is a 'Draft' feature applied to faces of components designed for plastic injection molding or metal casting?
     A) To provide a taper angle allowing easy ejection of the part from the mold
     B) To increase the hardness of the plastic resin
     C) To prevent oxidation of the mold steel
     D) To convert 3D geometry into 2D drawing lines
     >> CORRECT ANSWER: A) To provide a taper angle allowing easy ejection of the part from the mold

Q11. Which Creo feature is specifically engineered for adding structural stiffening webs between intersecting walls?
     A) Rib (Profile Rib / Trajectory Rib)
     B) Extrude Cut
     C) Chamfer
     D) Datum Axis
     >> CORRECT ANSWER: A) Rib (Profile Rib / Trajectory Rib)

Q12. What are the standard hole creation types provided by the Creo 'Hole' tool?
     A) Simple, Standard (Threaded/Clearance), and Sketched
     B) Square, Hexagonal, and Octagonal only
     C) Punched and Laser cut only
     D) Magnetic and Hydraulic
     >> CORRECT ANSWER: A) Simple, Standard (Threaded/Clearance), and Sketched

Q13. Which pattern type in Creo allows replicating features radially around a central cylindrical axis?
     A) Axis Pattern
     B) Direction Pattern
     C) Fill Pattern
     D) Table Pattern
     >> CORRECT ANSWER: A) Axis Pattern

Q14. In Creo, what capability do 'Relations' (Tools > Relations) provide in parametric modeling?
     A) Mathematical equations that drive dimensions based on other dimensions or parameters
     B) Bluetooth connections to CNC machines
     C) Email notifications when a file is saved
     D) Automatic color grading of 3D models
     >> CORRECT ANSWER: A) Mathematical equations that drive dimensions based on other dimensions or parameters

Q15. What is a 'Family Table' in Creo used for?
     A) Generating a collection of similar parts (instances) derived from a single generic model
     B) Managing user accounts and employee salaries
     C) Organizing computer hard drive directories
     D) Arranging color palettes in the rendering module
     >> CORRECT ANSWER: A) Generating a collection of similar parts (instances) derived from a single generic model

Q16. In Creo Assembly, which constraint aligns two planar faces so that their normal vectors point in opposite directions and touch?
     A) Mate
     B) Align
     C) Insert
     D) Orient
     >> CORRECT ANSWER: A) Mate

Q17. Which Creo Assembly constraint is commonly used to assemble a bolt or pin into a cylindrical hole in one step?
     A) Insert
     B) Tangent
     C) Fix
     D) Parallel
     >> CORRECT ANSWER: A) Insert

Q18. In Creo Mechanism Design, which connection joint allows pure rotational movement around a single axis (1 degree of freedom)?
     A) Pin joint
     B) Slider joint
     C) Cylinder joint
     D) Ball joint
     >> CORRECT ANSWER: A) Pin joint

Q19. What tool in Creo Assembly is utilized to identify physical overlapping between neighboring solid components?
     A) Global Interference / Clash Check
     B) Bill of Materials
     C) Explode State animation
     D) Render Studio
     >> CORRECT ANSWER: A) Global Interference / Clash Check

Q20. In Creo Sheetmetal design, what parameter represents the ratio of the neutral axis position to the sheet metal thickness during bending?
     A) K-Factor
     B) Young's Modulus
     C) Poisson's Ratio
     D) Shear Modulus
     >> CORRECT ANSWER: A) K-Factor

Q21. Which Creo Sheetmetal feature is used to unbend a formed sheetmetal part into its flat layout state?
     A) Flat Pattern / Unbend
     B) Extrude Cut
     C) Rip
     D) Form
     >> CORRECT ANSWER: A) Flat Pattern / Unbend

Q22. What is the primary file extension for a single 3D solid part model in PTC Creo?
     A) .prt
     B) .asm
     C) .drw
     D) .sec
     >> CORRECT ANSWER: A) .prt

Q23. What is the primary file extension for an Assembly model in PTC Creo?
     A) .asm
     B) .prt
     C) .drw
     D) .frm
     >> CORRECT ANSWER: A) .asm

Q24. How does Creo handle file versioning when saving a model repeatedly (e.g., saving `bracket.prt`)?
     A) Appends an incremental version number extension (e.g., `bracket.prt.1`, `bracket.prt.2`)
     B) Overwrites the previous file with no backup
     C) Compresses the file into a zip archive
     D) Renames the file to read-only
     >> CORRECT ANSWER: A) Appends an incremental version number extension (e.g., `bracket.prt.1`, `bracket.prt.2`)

Q25. In Creo Drawing (.drw), what functionality is used to automatically generate an associative Bill of Materials (BOM) table?
     A) Repeat Region in Table
     B) OLE object insertion
     C) Manual text typing
     D) Screenshot paste
     >> CORRECT ANSWER: A) Repeat Region in Table

Q26. In engineering drawings, what does a 'Section View' reveal that is not visible in standard exterior projection views?
     A) Internal geometry, ribs, holes, and wall thicknesses along a cutting plane
     B) The external surface finish color
     C) The total shipping package dimensions
     D) The customer contact address
     >> CORRECT ANSWER: A) Internal geometry, ribs, holes, and wall thicknesses along a cutting plane

Q27. In GD&T, what symbol represents the tolerance zone within which the axis of a cylindrical feature must lie relative to datum references?
     A) Position (True Position)
     B) Flatness
     C) Straightness
     D) Profile of a line
     >> CORRECT ANSWER: A) Position (True Position)

Q28. In Finite Element Analysis (FEA) with Creo Simulate, what are the two fundamental boundary conditions required for a static structural analysis?
     A) Constraints (supports) and Loads (forces/pressures)
     B) Fluid viscosity and ambient humidity
     C) Toolpath feed rate and spindle speed
     D) Electrical resistance and capacitance
     >> CORRECT ANSWER: A) Constraints (supports) and Loads (forces/pressures)

Q29. Which neutral 3D CAD data exchange file format is widely used for sending 3D geometry to manufacturing suppliers with full NURBS boundary representation?
     A) STEP (.stp / .step)
     B) STL (.stl)
     C) BMP (.bmp)
     D) MP3 (.mp3)
     >> CORRECT ANSWER: A) STEP (.stp / .step)

Q30. Which standard tessellated mesh file format is universally exported from Creo for rapid prototyping and 3D printing (Additive Manufacturing)?
     A) STL (Stereolithography)
     B) DWG
     C) PDF
     D) TIFF
     >> CORRECT ANSWER: A) STL (Stereolithography)
