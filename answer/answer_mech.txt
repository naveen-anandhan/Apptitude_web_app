Q01. What is PTC Creo primarily categorized as in engineering design?
     A) Operating system kernel utility
     B) Parametric 3D CAD / CAM / CAE modeling software
     C) Vector graphic illustration software
     D) Relational Database Management System
     >> CORRECT ANSWER: B) Parametric 3D CAD / CAM / CAE modeling software

Q02. In Creo Sketcher, what is the key difference between 'Weak' and 'Strong' dimensions?
     A) Weak dimensions apply only to 3D solids; Strong dimensions apply to 2D sketches
     B) Weak dimensions cannot be seen on screen; Strong dimensions are always visible
     C) Weak dimensions are measured in inches; Strong dimensions are measured in millimeters
     D) Weak dimensions are automatically generated by the Intent Manager; Strong dimensions are explicitly defined or modified by the user
     >> CORRECT ANSWER: D) Weak dimensions are automatically generated by the Intent Manager; Strong dimensions are explicitly defined or modified by the user

Q03. Which tool in Creo is used to create a 3D solid by linearly projecting a 2D sketch perpendicular to the sketch plane?
     A) Revolve
     B) Blend
     C) Extrude
     D) Sweep
     >> CORRECT ANSWER: C) Extrude

Q04. What essential geometric reference is mandatory when creating a solid feature using the 'Revolve' tool in Creo?
     A) A centerline / Axis of revolution
     B) A spherical datum coordinate
     C) A helical trajectory curve
     D) A chamfer vertex point
     >> CORRECT ANSWER: A) A centerline / Axis of revolution

Q05. What is the primary function of a 'Datum Plane' in Creo parametric modeling?
     A) Specifies the thermal conductivity of the alloy
     B) Defines the raw material cost of the component
     C) Renders photorealistic raytraced textures
     D) Serves as a reference plane for sketching, dimensioning, and feature placement
     >> CORRECT ANSWER: D) Serves as a reference plane for sketching, dimensioning, and feature placement

Q06. Which tool in Creo creates a solid feature by sweeping a planar cross-section along an open or closed trajectory path?
     A) Sweep
     B) Shell
     C) Extrude
     D) Hole
     >> CORRECT ANSWER: A) Sweep

Q07. What is the engineering purpose of applying a 'Round' (Fillet) to the re-entrant corners of a mechanical part?
     A) To increase the structural weight of the casting
     B) To reduce stress concentrations and eliminate notch effects
     C) To speed up 3D printing slicing
     D) To make the CAD file size smaller
     >> CORRECT ANSWER: B) To reduce stress concentrations and eliminate notch effects

Q08. Which dimension scheme option is available when defining a standard 'Chamfer' in Creo?
     A) Volume x Density
     B) Diameter x Pitch only
     C) Radius x Arc Length only
     D) 45 x D, D x D, D1 x D2, and Angle x D
     >> CORRECT ANSWER: D) 45 x D, D x D, D1 x D2, and Angle x D

Q09. In Creo, which feature is used to hollow out the interior of a solid body while maintaining specified wall thickness?
     A) Shell
     B) Draft
     C) Mirror
     D) Rib
     >> CORRECT ANSWER: A) Shell

Q10. Why is a 'Draft' feature applied to faces of components designed for plastic injection molding or metal casting?
     A) To increase the hardness of the plastic resin
     B) To prevent oxidation of the mold steel
     C) To provide a taper angle allowing easy ejection of the part from the mold
     D) To convert 3D geometry into 2D drawing lines
     >> CORRECT ANSWER: C) To provide a taper angle allowing easy ejection of the part from the mold

Q11. Which Creo feature is specifically engineered for adding structural stiffening webs between intersecting walls?
     A) Datum Axis
     B) Rib (Profile Rib / Trajectory Rib)
     C) Chamfer
     D) Extrude Cut
     >> CORRECT ANSWER: B) Rib (Profile Rib / Trajectory Rib)

Q12. What are the standard hole creation types provided by the Creo 'Hole' tool?
     A) Square, Hexagonal, and Octagonal only
     B) Magnetic and Hydraulic
     C) Simple, Standard (Threaded/Clearance), and Sketched
     D) Punched and Laser cut only
     >> CORRECT ANSWER: C) Simple, Standard (Threaded/Clearance), and Sketched

Q13. Which pattern type in Creo allows replicating features radially around a central cylindrical axis?
     A) Table Pattern
     B) Fill Pattern
     C) Direction Pattern
     D) Axis Pattern
     >> CORRECT ANSWER: D) Axis Pattern

Q14. In Creo, what capability do 'Relations' (Tools > Relations) provide in parametric modeling?
     A) Automatic color grading of 3D models
     B) Mathematical equations that drive dimensions based on other dimensions or parameters
     C) Bluetooth connections to CNC machines
     D) Email notifications when a file is saved
     >> CORRECT ANSWER: B) Mathematical equations that drive dimensions based on other dimensions or parameters

Q15. What is a 'Family Table' in Creo used for?
     A) Generating a collection of similar parts (instances) derived from a single generic model
     B) Managing user accounts and employee salaries
     C) Organizing computer hard drive directories
     D) Arranging color palettes in the rendering module
     >> CORRECT ANSWER: A) Generating a collection of similar parts (instances) derived from a single generic model

Q16. In Creo Assembly, which constraint aligns two planar faces so that their normal vectors point in opposite directions and touch?
     A) Insert
     B) Align
     C) Mate
     D) Orient
     >> CORRECT ANSWER: C) Mate

Q17. Which Creo Assembly constraint is commonly used to assemble a bolt or pin into a cylindrical hole in one step?
     A) Parallel
     B) Insert
     C) Tangent
     D) Fix
     >> CORRECT ANSWER: B) Insert

Q18. In Creo Mechanism Design, which connection joint allows pure rotational movement around a single axis (1 degree of freedom)?
     A) Pin joint
     B) Ball joint
     C) Slider joint
     D) Cylinder joint
     >> CORRECT ANSWER: A) Pin joint

Q19. What tool in Creo Assembly is utilized to identify physical overlapping between neighboring solid components?
     A) Explode State animation
     B) Bill of Materials
     C) Global Interference / Clash Check
     D) Render Studio
     >> CORRECT ANSWER: C) Global Interference / Clash Check

Q20. In Creo Sheetmetal design, what parameter represents the ratio of the neutral axis position to the sheet metal thickness during bending?
     A) K-Factor
     B) Poisson's Ratio
     C) Young's Modulus
     D) Shear Modulus
     >> CORRECT ANSWER: A) K-Factor

     >> CORRECT ANSWER: C) .asm

Q24. How does Creo handle file versioning when saving a model repeatedly (e.g., saving `bracket.prt`)?
     A) Compresses the file into a zip archive
     B) Appends an incremental version number extension (e.g., `bracket.prt.1`, `bracket.prt.2`)

     >> CORRECT ANSWER: B) Appends an incremental version number extension (e.g., `bracket.prt.1`, `bracket.prt.2`)

Q26. In engineering drawings, what does a 'Section View' reveal that is not visible in standard exterior projection views?
